Riya(Coordinator) The group chat can't agree on a trip. Riya opens dil-chahta-hai.vercel.app.
  • Trip name
  • Names of all 5 people
  • 3–4 date options
  • Answer deadline (IST)
 No account needed. She gets a private organiser link, which is the only way to lock or finalise the trip.
  • Shares trip link + 6-digit PIN on WhatsApp
  • Watches who has answered
  • Can lock early, unlock, or make a new PIN
 Taps Mark as final on the winner. Everyone sees "Decided: Goa, 10–14 Nov" and answers lock.
Friends(x 4) Trip link and PIN arrive in the WhatsApp group.
  • PIN, then "Who are you?"
  • Budget per person (₹)
  • Dates that work
  • Trip type: beach, hills, city, adventure
  • Deal-breakers: international, trekking, overnight journey
  • Costs assume travel from Pune
  • Their exact budget is never shown to the group
  • Answers can be edited until the deadline
 Save answers. "Switch" fixes a wrong name; "Is this really you?" protects someone else's answers. See who has answered and the top 3 options, each with a photo, cost and plain reasons (e.g. "Asha: over budget").
Trip Planner App(Next.js on Vercel) A page opens or a button is pressed (a server action). Form data + the friend's signed PIN cookie, or Riya's organiser link.
  • Checks access before anything else
  • Deadline, early lock and final choice
  • 10 destinations from Pune
 Floor, then average: an option fails if anyone is blocked, over budget or scores under 40. Passing options rank by group average, then lowest score, then cost. Ranked result cards with Domestic / International badges, "Provisional" or "Locked" label. No budgets in the page.
Gemini(LLM) Not used in this build. Ranking is a fixed, explainable rule, so every friend can see why an option won or was flagged. No AI calls, no API key, no running cost.
Supabase(Database) A request from the app's server. The browser never talks to the database. New trip, a friend's answers, or a PIN attempt. Tables trips responses destinations. Row-level security on, no public access. Mumbai region. try_pin() locks the trip row per attempt: 10 wrong tries, then a 15-minute pause. Answers are saved or updated. Saved rows go back to the server only.
Other API(Vercel Cron) Once a day, on a schedule. A secret token (CRON_SECRET). Free Supabase projects pause after a week without use. /api/keepalive runs one tiny query. The database stays awake, so a trip link never opens to an error.
